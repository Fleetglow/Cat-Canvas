# API 生成节点极宽高比预设设计

## 目标

在 API 生成节点的图片比例选择器中增加 `1:3` 和 `3:1`，并支持 1K、2K、4K 分辨率。

## 实现

- 沿用现有固定尺寸预设机制，不修改后端接口。
- `1:3` 使用 `512x1536`、`688x2048`、`1280x3840`。
- `3:1` 使用 `1536x512`、`2048x688`、`3840x1280`。
- 比例选择器和输出详情同步显示 `1:3`、`3:1`。
- 请求继续仅提交最终 `size` 字符串。

## 验证

- 静态测试确认两个比例均出现在尺寸映射、下拉选项和详情名称映射中。
- 校验 JavaScript 语法并运行现有 Node 测试。
